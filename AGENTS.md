# Portfolio maintenance

- Static site for GitHub Pages. All pages are generated by `node scripts/build.mjs` (no dependencies); commit the generated HTML.
- Edit content (news, publications, experience, projects) in the data section at the top of `scripts/build.mjs`, then rebuild.
- Styling is the compiled stylesheet in `assets/css/site.css`; only classes already in it are available. Interactions live in `assets/js/site.js`, the hero web animation in `assets/js/web.js`.
- Portrait: `assets/img/profile.jpg`; publication figures: `assets/figures/` (set `fig` per paper in the build script).
- CV source is `assets/cv/CV.tex`; rebuild with `pdflatex` and keep `assets/cv/Apurbo-CV.pdf` in sync.
- Do not invent publication links or research results; the CV is the source.
