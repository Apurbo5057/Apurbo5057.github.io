# Apurbo — Research Portfolio

Personal site of **Md. Mosharaf Hossain Apurbo**, CSE undergraduate at BUET. Live at https://apurbo5057.github.io/

Pages: Home, About, Publications, Experience, Blog, Contact. Light and dark themes, static HTML, no framework.

## Develop

```sh
node scripts/build.mjs          # regenerate HTML from the data in the script
python -m http.server 8765      # preview at http://127.0.0.1:8765
```

Content lives at the top of `scripts/build.mjs`. See `AGENTS.md` for details.
